Workflow guide · replace an appearance or add an outfit
  1. Open New…, choose the starting fighter and purpose, then start the project. The starting fighter supplies combat, body and UI defaults. For an open appearance project, choose Existing fighter and Apply project purpose & target.
  2. Use Import original body; the preview loads automatically. To mix donors, open Advanced: mix donors. Import the body before painting; importing a body again clears previous texture imports.
  3. In Textures, select a shape and Import RGB PNG… with the same UV layout. For Pockets pants, use the complete A001 atlas. Refresh the preview.
  4. Apply project details, Save project as an editable .ffnyfighter, then Export Custom Fighter Mod… to a new ZIP filename.
  5. In the matching game build, import and enable the ZIP under Mods > Fighters. Select the original fighter, choose the added numbered outfit if applicable, then verify it in battle.

Replacement changes the original appearance; an added outfit keeps the original. The limit is three outfits total, with shared combat, stats and voice. Test replacement and extra-outfit packs separately. Body PNGs do not recolor the separate 2D selector portraits.

To continue editing, open the saved project. To recover an exported pack, extract its ZIP, then use Import fighter from pack… and select the folder containing fighters.json. Independent single-fighter packs and single-target appearance overrides are supported.
