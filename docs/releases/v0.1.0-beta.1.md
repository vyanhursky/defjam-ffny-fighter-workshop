# Def Jam FFNY Fighter Workshop — 0.1 Beta 1

The first packaged beta of the offline Create-a-Fighter and profile editor for
Def Jam: Fight for NY Recomp.

## Downloads and launch

- **Windows x64:** extract the ZIP and run
  `defjam-ffny-fighter-workshop.exe`. Keep the complete folder together.
- **macOS Apple Silicon / Intel:** choose the matching ZIP, extract it and open
  `defjam-ffny-fighter-workshop.app`. The app uses ad-hoc signing and is not
  notarized. If macOS blocks the downloaded app, use System Settings → Privacy
  & Security → Open Anyway for this app.
- **Linux x64:** extract the tar.gz and run
  `./defjam-ffny-fighter-workshop/defjam-ffny-fighter-workshop` in a desktop
  session. Runtime libraries/prerequisites are listed in
  [desktop platforms](https://github.com/vyanhursky/defjam-ffny-fighter-workshop/blob/v0.1.0-beta.1/docs/desktop-platforms.md).

Python, Qt WebEngine, NumPy, Pillow and the offline UI are bundled. The archives
contain the editor, not a game executable, saves or a game dump. Use your own
installed Recomp data. The reused app icon and approved documentation captures
include game artwork outside the project's MIT license.

## Included

- Browse and preview existing Xbox-based Recomp fighter profiles.
- Change five training stats within 0–50, cash and development points.
- Combine up to three supported retail fighting styles.
- Try on retail clothing, colors and fits; Equip stages changes, Save writes them.
- Preview saved face/body/hair/jewelry/tattoos, three poses and four lighting modes.
- Full-profile export/import and duplication with preserved Story bytes.
- Backups, unknown-byte preservation, stale-source checks and collision refusal.
- Native macOS installer-directory discovery and the Recomp app icon.

## Start with copied saves

Choose the Recomp data directory containing `save` and `extracted`. macOS tries
`~/Library/Application Support/DefJamRecompiled/data` automatically. A title
folder alone does not imply a fighter profile exists. Use Open data directory
for a custom installation. Close the game that uses those saves before editing.
Initial asset conversion may take several minutes; the cache and backups stay
in a separate editor workspace. Nothing is uploaded or downloaded by the editor.

## Validation and beta limits

The release assets come from the same source commit's native Windows x64,
macOS arm64/x64 and Ubuntu 22.04 x64 CI. Each archive is checksum-verified,
extracted into a path with spaces/non-ASCII text, and its frozen offline
WebGL 2/WebChannel startup and icon checked. Mac signatures are verified strictly.
Linux runs all 40 Python cases; Windows passes 37 with three platform/filesystem
skips, and each Mac passes 38 with two filesystem skips. Four pose tests run on
every target. The separate local Apple Silicon 29-step editor check covers
real copied-save edit/backup/export/import/duplication. See provenance.json for
the exact source commit, CI run, package hashes and startup receipts.

CI uses hosted software graphics adapters; those startup checks do not qualify
all physical GPUs, Wayland or every native gameplay/editing combination.
Existing Recomp profiles only: create a Story fighter in the game first. Named
fighter moveset overrides, fresh Story-profile creation and custom meshes/textures
are outside this beta. Wardrobe-inspired/Relaxed poses and lighting are preview
approximations. Cash 10,000,000 and development 100,000 are conservative beta caps.

## Integrity

Each package has a `.sha256` sidecar. `SHA256SUMS` covers all four archives;
`provenance.json` records their source and CI evidence. Preserve the whole
extracted application folder. Please report the OS, profile action/item,
expected result and observed result; keep saves and extracted assets private.
