# Terminology

- **Story profile:** a complete game save, including the Story fighter, career,
  inventory and currency. A `.djprofile` transfers the complete profile.
- **Project:** a portable `.ffnyfighter` authoring file for a CAF or retail-based
  fighter, containing fighter settings and imported assets without Story progress.
- **Outfit:** one selectable look belonging to a fighter. CAF outfits share stats,
  moves and performance settings, with their own appearance and artwork.
- **Game version / runtime:** the selected Recomp build whose tools validate and
  compile exports. Workshop's version is separate. Game setup lists capabilities;
  stable 1.2.0 and 1.2.0 beta 2 do not offer the same tools.
- **Recipe:** the fighter description sent to the runtime compiler during export.
  There is one current CAF recipe format. Choose a compatible game build rather
  than a numbered recipe or project version.
