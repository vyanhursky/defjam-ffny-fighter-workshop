# Fighter Workshop 0.2.0

Offline desktop packages for Windows x64, macOS Apple Silicon, macOS Intel and
Linux x64. Python and Qt are included. Extract the complete package; launch the
executable on Windows/Linux or the `.app` on macOS. Select your own Recomp game
data through **Game setup**. No game dump, runtime executable or save is included.

## Changes

- CAF and retail fighter projects share grouped menus, outfit navigation,
  Voice/AI/Entrance controls, pending changes, Undo/Reset and pinned Save/Export.
  Changing the moves donor preserves staged stats and explicit performance edits.
  CAF wardrobe and face controls remain specific to CAF bodies.
- Prepare original voice clips together, browse with Previous/Next and play
  without repeating extraction. **Save WAV** opens a native destination chooser,
  making the exported file location explicit.
- Stage original retail menu artwork once, then browse all layouts locally.
  Compare imports against the original donor; clearing an override restores the
  donor preview. Reference previews do not become project/export overrides.
- Clearer game setup progress, runtime capability reporting and export readiness;
  improved profile/project workflows, bridge validation, bounded caches, typed
  project contracts, dependency records and offline documentation.
- Optional retail source-animation preview and standalone retail outfit
  collections are present with explicit capability gates, described below.

## Runtime compatibility

The main menu parity, voice preparation/saving and original artwork previews work
with the existing compatible Recomp 1.2.0 beta 2 authoring tools. Runtime PR #267
is optional capability/discovery support; it is not required for those changes.

Retail source-animation preview requires `retail-animation-preview-1`, supplied
by companion runtime PR #269. This is an offline authoring-tools update; a game
executable rebuild is not needed solely for this preview. Older tools keep the
feature unavailable with an explanation.

Exporting multiple selectable outfits for a standalone retail fighter requires
`standalone-retail-outfits-1` and the FWR3 runtime support from companion runtime
PR #270. Installing/playing that export requires the matching runtime build.
Older tools can still preview a selected look. These requirements concern
standalone retail collections, rather than ordinary CAF outfit projects.

**No runtime PR is merged or changed as part of this Workshop release.** The
Workshop does not install companion runtime branches. Capability checks explain
when an update is needed instead of silently generating unsupported exports.

## Validation and limits

The owner accepted Windows hands-on testing of the updated Workshop. Focused
Windows Qt/WebChannel/WebGL tours cover menu parity, voice playback and original
artwork staging; source tests cover codecs, transaction safety and release gates.
Each published platform package comes from the tagged source's successful native
CI build and relocated frozen startup check. SHA256SUMS and provenance.json bind
the archives to that exact source commit and CI run.

macOS/Linux native CI build/startup checks are not manual editor/game acceptance.
Private native pilots qualify specific exports, not every possible combination.
Source animation is an approximate preview with codec/track limits; face sculpt
and PS2 recovery remain experimental. Keep backups and test exports separately
from your main saves. macOS packages are ad-hoc signed, not notarized.

Software is GPL-3.0-only. Third-party notices are included; the approved icon and
documentation game artwork remain outside the software license. Original game
assets, decoded caches, voice exports, private projects and saves stay local.
