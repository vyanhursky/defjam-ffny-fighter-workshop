# Def Jam FFNY Fighter Workshop — 0.1 Beta 2

The second beta of the offline Create-a-Fighter and profile editor for Def Jam:
Fight for NY Recomp. It matches Recomp **v1.2.0-beta.2**: fighters exported by
this build use the one recipe format that runtime reads. Custom fighters exported
by earlier development builds of the Workshop are refused by it, so export them again.

## Downloads and launch

Same as Beta 1: extract the archive for your system and run the app (Windows x64,
macOS Apple Silicon or Intel, Linux x64). The macOS app uses ad-hoc signing and is
not notarized; use System Settings, Privacy & Security, Open Anyway if it is
blocked. Python, Qt WebEngine, NumPy, Pillow and the offline UI are bundled. The
archives contain no game executable, saves or game dump.

## What is new since Beta 1

- **A Home screen.** The editor opens on four choices: Story character editor,
  Fighter from a Create-a-Fighter, Fighter from a retail fighter and Retail
  fighter editor. Each has New and Open buttons, tells you plainly when the
  chosen game version cannot do it yet, and the last six projects are listed
  for one-click reopening. Every page has a Home button and asks before
  discarding unsaved changes.
- **Game setup.** One dialog takes the Recomp folder (found automatically on
  Windows), lists the installed game versions and says what each can do:
  export, voice and animation tools, retail menu import, retail fighter studio.
  The data and game folders are remembered between launches.
- **Fighter projects.** Create a custom fighter from a Create-a-Fighter or from
  a retail fighter, with up to three outfits, facial authoring, voice,
  entrance and victory, AI personality, performance and menu artwork. One project
  format and one CAF recipe format replace the earlier versions.
- **HD textures.** Square 256, 512, 1024 and 2048 px PNG atlases import and
  export through the runtime's HD system.
- **Safer saves.** Restore a profile backup from the left column (a restore backs
  up what it replaces); saving a retail moveset into a real Story profile asks you
  to acknowledge it first; saves, exports and restores finish with a summary that
  has an Open folder button. Messages stay in a log in the footer.

## Testing and limits

237 Python tests pass (3 platform skips). The window was driven in the real Qt
app on copies of saves: all four Home workflows, recent projects, project
round trips, backups and an export that the Recomp beta 2 runtime installed and
played on Windows. The native "leave without saving?" prompt, Ctrl+S and Ctrl+Z,
retail export with a real body import and the 3D preview were not exercised in
that pass. macOS and Linux packages come from CI and have not been run by hand yet.
Game version 1.2.0 (the stable-line installed app) does not include the export,
tools or retail commands; use the Recomp 1.2.0 beta 2 build or a source checkout.
Keep your own artwork, projects and captures private; the reused app icon and
documentation captures include game artwork outside the project's licence.
