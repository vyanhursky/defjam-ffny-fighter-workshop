# Fighter Workshop 0.3.1

Pairs with [Def Jam Recompiled 1.2.1](https://github.com/vyanhursky/DefJamFFNY-recomp/releases/tag/v1.2.1)
for complete reviewed CAF entrance/victory projects. Offline packages include
Python and Qt for Windows x64, macOS Apple Silicon/Intel and Linux x64. Extract
the complete package and launch its executable or macOS app. No game dump,
compiled game, save, fighter project or recording is included.

## Changes

- Preserve authored Blaze `CE_113A` victory mouth tracks with their extro WAV
  and hash, alongside independent entrance tracks and intro audio.
- Preserve the fixed native left-finger pose and timed envelope, including the
  explicit full-victory hold. Body, camera, wrist and right-hand motion stay
  separate; arbitrary rigs, destinations and graph programs remain refused.
- Check the selected compiler for `caf-victory-mouth-1`, `caf-left-fingers-1`
  and, when needed, `caf-left-fingers-hold-1`. Older compilers receive a clear
  export refusal instead of dropping the performance.

Author the reviewed controls with the paired Blender bridge. Its half-speed
sound/animation preview and sound-delay calibration leave export timing intact.
The normal Workshop source-animation preview does not evaluate facial/finger
tracks; an export or Blender render is not native gameplay acceptance.

Existing HD CAF appearance, final attributes, Team artwork, normal corrections,
entrances and ordinary voice replacements retain their existing meaning.
New victory/finger exports require game1.2.1; unrelated older projects retain
previous compatibility. This adds no general-purpose rig or arbitrary donor importer.

checks; Ruff and mypy pass. Native CI builds/relocated startup cover all four
package targets. SHA256SUMS and provenance bind published archives to the exact
successful default-branch build, which the staging workflow audits.

CAFdefault outfit/Terrordome, through results:204entrance/201victory samples
